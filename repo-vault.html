🔑 GitHub Token

Without a token GitHub allows only 60 requests/hour. With a free token you get 5000/hour — no more "rate limit" errors.

Create one at github.com/settings/tokens → "Generate new token" → no scopes/permissions needed (public data only). The token is stored only in your browser, never sent anywhere except api.github.com.
